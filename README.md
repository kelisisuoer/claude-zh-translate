# Claude Code 中文翻译

在原生 `claude` 命令行里直接用中文：

- **发送前**：你打的中文由翻译模型译成英文，**只把英文发给 Claude**。你那一行照样显示你打的中文，下面一行 `↳ …` 是实际发出去的英文。
- **回复时**：Claude 用英文回复。每段写完就在后台翻译，译好后在原处变成中文；也可以设成英文下面附中文。代码块、表格、路径和命令保持原样。
- **英文消息**：英文提问不受影响，照常发送，回复也不翻译。

这是一个 Claude Code 插件（装在 `~/.claude/skills/zh-translate`），Claude Code 启动时会自动加载。

## 要求

- **Claude Code 2.1.287 或更新**：用 `claude --version` 查看，`claude update` 升级。插件用的是 Claude Code 新的插件接口，更老的版本加载不了。
- **Node.js 18 或更新**：用 `node --version` 查看。
- **已登录 Claude Code**：翻译用的是你自己的账号，会计入你的用量或额度。

## 安装

1. 解压到任意位置。
2. 运行安装脚本：
   - Windows：双击 `install.cmd`；或者在解压目录打开终端，运行 `node install.mjs`。
   - macOS / Linux：在解压目录运行 `node install.mjs`。
3. 重新打开 `claude`。

重复运行安装脚本是安全的，可以用来升级。你的模式、范围、模型和词表都会保留。

如果以前装过旧版（用 settings.json 里 hook 实现的那一版），安装脚本会自动做两件事，都会先备份：

- 去掉旧版的 hook；
- 去掉旧版的 `/zh`、`/zh-model` 命令。

## 用法

| 命令 | 作用 |
|---|---|
| `/zh` | 打开设置菜单：开关、回复怎么显示、翻译哪些回复、翻译模型。上下键或 Tab 选择，回车切换，Esc 关闭 |
| `/zh on` / `/zh off` | 开启 / 关闭翻译 |
| `/zh only` | 回复只显示中文（默认） |
| `/zh both` | 英文回复下面附上中文和翻译费用 |
| `/zh all` | 每条回复都翻译（默认） |
| `/zh final` | 只翻译每轮最后的回复，Claude 中间的工作过程保持英文；你的消息照常翻译 |
| `/zh-model` | 弹出列表，上下键或 Tab 选择翻译用的模型，回车确认，Esc 取消 |

几点说明：

- **设置立即生效**：比如从 `only` 改成 `both`，屏幕上已经有的回复会马上重画。
- **不花钱**：这些命令由插件自己处理，不会发给 Claude。
- **翻译中的回复**：先显示英文，并标注“翻译中…”，译好后换成中文。

### 词表

`~/.claude/zh-translate/glossary.txt`，每行写一条 `中文 = English`，两个方向的翻译都会按它统一用词。想让某个词保持中文不翻，就写成 `词 = 词`。改完后下一次翻译就生效。

翻译回复时，你自己那条中文消息也会一并给翻译模型参考，所以译文会尽量沿用你的说法。

### 状态栏（可选）

如果你用 [ccstatusline](https://github.com/sirmalloc/ccstatusline)，可以加一个“自定义命令”组件，显示类似 `译: Sonnet 5.5 $0.012` 的内容（当前翻译模型和本会话的翻译费用）。要填的命令在安装结束时会打印出来，格式是：

```
"<node 路径>" "<家目录>/.claude/zh-translate/status.mjs"
```

## 速度和费用

费用按各模型的 API 价格，用实际用掉的 token 估算。用订阅账号时，消耗的是订阅额度。

| 模型 | 速度 | 译文 |
|---|---|---|
| Haiku 4.5 | 最快，约 2 秒一段 | 偏直译，偶尔翻错专有名词 |
| Sonnet 5.5（默认） | 快，约 3 秒一段 | 自然 |
| Opus | 较慢 | 自然 |
| Fable | 最慢、最贵 | 自然 |

`/zh-model` 的列表里有每个版本按一段回复估算的价格。翻译一条普通回复一般在 $0.002–0.02 之间，远低于 Claude 本身回复的费用。

## 限制

- **对话记录保存的是英文**：你的消息和 Claude 的回复都以英文保存。屏幕上显示的是中文，导出对话或用 `--resume` 恢复后看到的取决于翻译是否还在；插件会把本会话的翻译另存一份，恢复会话时尽量照样显示中文。
- **这些内容保持英文**：工具调用、思考过程、权限确认框。
- **`claude -p` 脚本模式**：发送的翻译和 `final` 范围的翻译照常工作。但 `all` 范围下最后一段回复的翻译，可能在程序退出时来不及完成；屏幕上的显示只在交互界面里有。

## 卸载

Windows 双击 `uninstall.cmd`，其他系统运行 `node uninstall.mjs`。卸载会删除：

- 插件；
- 设置和词表；
- 临时文件；
- 旧版留下的 hook 和命令（如果有）。

如果在状态栏里加过翻译组件，需要手动删掉。

## 原理

- **发送前**：插件在 `prompt.submit` 把你的消息换成英文译文，再交给 Claude。
- **显示你的消息**：用 `UserMessage` 的绘制钩子，把你那一行画成中文。
- **显示回复**：回复的每段存下时（`session.append`）在后台翻译，`AssistantMessage` 的绘制钩子把它画成中文。
- **只改显示**：屏幕上的中文只是显示，保存下来的对话是英文。
- **隐私**：翻译走的是你自己登录的 Claude 账号（`$.model.complete`），不经过任何第三方服务。
